# Example inputs

Material for running the demo path end to end without inventing anything on the spot.

| File | What it is |
|---|---|
| `example-resume.txt` | An invented backend engineer. Pairs with the `development` criteria file. |
| `example-answers.md` | Prepared answers, so the interview can be walked through at a predictable pace. |

Everyone here is invented. The resume is deliberately realistic in the ways that
matter to the system: it has quantified claims worth probing, one skill that
appears only in the skills list and is never described in a role, and a
half-year internship, which is the case `totalYearsExperience` counts at half.

## The demo path

1. `/apply` — upload `example-resume.txt`, pick **Software developer**, level **Senior**.
2. Work through the interview using `example-answers.md`, or answer freely.
3. Finish. The assessment, the skill diagram, and the practical task appear.
4. Do the task, or skip it.
5. `/manager/candidates` — the new candidate appears in the ranked list.
6. Open the candidate, then **Download the record** for the interview and homework transcript.
